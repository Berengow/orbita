# ORBITA — демо-тур

Статический виртуальный тур. Сервер не нужен: GitHub Pages отдаёт эти файлы как есть.

Три зала — Зал, Галерея, Атриум. Точки переключают сцены без перезагрузки страницы.

## Адрес

После включения Pages сайт открывается здесь:

https://berengow.github.io/orbita/

## Как залить свой тур

В конструкторе ORBITA нажмите «Скачать сайт» и распакуйте ZIP в корень этого репозитория: index.html должен лежать рядом с player/, vendor/ и panoramas/. Файл .nojekyll уже на месте — не удаляйте его.

Pages: Settings, Pages, Deploy from a branch, ветка main, папка / (root).
